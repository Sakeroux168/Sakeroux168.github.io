# 我的小铺 · 使用说明

一个纯静态网站，不用服务器、不用数据库、不用买域名，免费托管在 GitHub Pages 上。

## 文件说明

```
index.html        首页（软件 / 动态 / 开源 / 实验室 / 定制 / 赞助 / 联系）
product.html      软件详情页（地址是 product.html?id=软件id）
posts.html        教程和公告列表
post.html         文章页（地址是 post.html?id=文章id）
data/site.js      ★ 网站全部内容都在这里，平时只改这一个文件
posts/            ★ 文章正文，一篇一个 .md 文件
assets/           样式和脚本（motion.js / motion.css 是滚动动效），一般不用动
fonts/            标题字体「得意黑」（免费可商用，许可证在同一个文件夹里）
images/           放图片：头像、收款码、软件截图
```

## 平时怎么改

- **改名字、介绍、联系方式**：打开 `data/site.js`，改最上面那几行。
- **加一个软件**：复制 `products` 里的一整段 `{ ... }`，改掉 `id`（只能用英文）和内容。
- **改价格**：改 `plans` 里的 `price`。`0` 表示免费。
- **放演示视频**：把视频传到 B 站，把 BV 号填进 `bilibili`。
- **放下载包**：用蓝奏云或 123 云盘（国内下载快），把分享链接填进 `downloads`。
- **放图片**：把图片放进 `images/`，文件名和 `site.js` 里写的一致就行。没放的图会显示虚线框提醒你。

需要的图片：

| 文件名 | 是什么 |
|---|---|
| `avatar.png` | 头像（正方形） |
| `wechat-qr.png` | 加你微信的二维码 |
| `pay-wechat.png` | 微信收款码（建议用「个人经营收款码」，在微信「收付款」里开通，不需要营业执照） |
| `pay-alipay.png` | 支付宝收款码 |
| `wechat-reward.png` | 微信赞赏码 |
| `baijiahao-cover.png` 等 | 软件截图（16:9 最好） |

不用的收款方式，直接在 `site.js` 的 `pay` 里删掉那一行。

## 写教程和公告

1. 在 `posts/` 文件夹里新建一个 `.md` 文件，比如 `posts/zhihu-faq.md`，用记事本写正文就行。
2. 在 `data/site.js` 的 `posts` 里加一段：

```js
{
  id: "zhihu-faq",               // 英文，不能重复
  type: "教程",                  // 只能是「教程」或「公告」
  title: "知乎发布助手常见问题",
  date: "2026-10-10",            // 按日期从新到旧排序
  product: "zhihu",              // 填软件 id，文章也会出现在那个软件的详情页；不相关就删掉这行
  summary: "一句话简介",
  file: "posts/zhihu-faq.md"
},
```

正文支持的写法：

```
## 大标题        ### 小标题
**加粗**         `代码`
- 列表           1. 有序列表
> 引用           --- 分割线
[链接文字](网址)  ![](images/图片.png)
```

## 滚动动效

动效都在 `assets/motion.js` 和 `assets/motion.css` 里，不依赖任何外部库。

- 每个区块滚到屏幕中间时，背景会慢慢变色。颜色在 `style.css` 里搜 `data-tone` 就能改。
- 软件区在电脑上会变成横向长廊（屏幕宽度 900 以上），手机上是普通的竖排。
- 访客在系统里开了「减少动态效果」的话，动效会自动关掉，网站照常能用。
- 想关掉某个效果：打开 `motion.js`，在 `refresh()` 里删掉对应那一行。

## 免费上线（GitHub Pages）

1. 在 GitHub 新建一个仓库，名字必须是 `你的用户名.github.io`，设为 Public。
2. 把这个文件夹里的所有文件上传到仓库（网页上直接拖进去就可以）。
3. 进入仓库的 **Settings → Pages**，Source 选 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`，保存。
4. 等一两分钟，打开 `https://你的用户名.github.io`，网站就上线了。

以后改了 `site.js` 再上传一次，网站会自动更新。

> 国内访问 github.io 大多数时候正常，偶尔会慢。等以后做大了，再考虑买域名、上国内服务器（需要备案）。

## 收款的几点提醒

- **爱发电**：个人可以注册，支持微信、支付宝，平台抽成约 6%。很适合做赞助，也能卖东西。
- **个人收款码**：收款码只适合小额零售，长期大量收款可能被风控限额，金额大了建议分散到爱发电。
- **USDT**：国内 USDT 交易不受法律保护，换成人民币时容易碰到「黑钱」导致银行卡被冻结。只收熟人的，换汇走正规渠道，金额不要大。
